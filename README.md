# 灵动网速 IslandSpeed 1.3.8

用灵动岛查看本机 Wi-Fi 与蜂窝接口的上下行速率。紧凑视图左侧显示下载，右侧显示上传。长按可查看本次监控时长、预约倒计时和换卡操作。此版基于 `main` 的 `743e2ce`，构建号 29。

## 安装和使用

1. 在 1.3.7 仓库的根目录解压更新包，按目录覆盖已有文件。
2. 提交到 `main` 后，在 **Actions → Build unsigned IPA → Artifacts** 下载 **IslandSpeed-unsigned**。保留 Widget 扩展和两个目标的 App Intents 元数据，使用和已安装版本一致的签名 App ID 覆盖安装。装好后打开 App 一次，设置页底部可核对版本和构建号。
3. 在「监控」页点「开始监控」。默认每 0.25 秒采样，最近一秒的字节数按实测时间加权，变化的读数默认每秒最多提交一次。刷新间隔可在「设置」页调整。定位辅助可选，打开后可能增加耗电。坐标不记录、不上传。
4. 接力间隔可选 120、150、180、210、240、270 或 300 秒，默认 240 秒，监控中可直接修改。自动接力开启时，App 按新间隔重排尚未启动的预约。监控页显示实际预约时间，以及前台每 10 秒重排的进度。长按灵动岛点「新增预约」，每次成功后增加一个预约。
5. 预约耗尽时，长按灵动岛，点「打开并补齐」。App 进入前台后创建新活动并尝试补齐 4 个预约。名额不足时，可在「查看预约」中点「重排接力」。

## 本次更新

- 展开卡显示「本次监控」时长，手动刷新和预约换卡后继续累计。右侧「运行」显示当前网速卡的使用时间。
- 展开卡上的手动换卡按钮统一为「刷新」。预约用完时仍可点「打开并补齐」。
- 若旧版已换过卡且没有保存最初的开始时间，展开卡显示「本次监控 —」。停止监控后重新开启即可开始计时。
- 覆盖安装后，打开 App 会尝试替换仍在使用的旧版网速卡。定位辅助、刷新频率、接力间隔等本机设置随覆盖安装保留。
- 设置页底部显示当前安装的版本和构建号。
- 首页点「停止监控」立即停下采样，并结束网速卡和剩余预约。
- 长按灵动岛点「新增预约」成功后，预约数进入下一次采样检查。每个系统送达的点击最多新增一个预约。
- 灵动岛各种形态的网速数字为白色，方向箭头保留颜色。
- iOS 26 及以上版本的「监控 / 设置」使用系统液态玻璃底栏。
- 接力使用标准实时活动。系统预约到点会发送启动提醒，紧凑或展开由 iOS 决定。
- 修复灵动岛按钮视图的 Swift 编译错误。
- 关闭自动接力后，长按灵动岛可点「刷新」手动更换网速卡，预约继续保持关闭。
- 展开卡的「预约已用完」和「运行」「下次」共用右侧时间列。
- 点「刷新」后，为新活动设置可用的更高展示优先级。新活动就绪后留出短暂交接时间再结束旧活动，新活动未就绪时保留旧活动。
- 监控中可关闭自动接力并解除待启动预约。在预约弹层解除全部预约后，本次停留在 App 前台期间暂停自动补排。

- 主界面分为「监控」和「设置」，刷新间隔、接力间隔及定位辅助设置会保存在本机。A2「燕麦咖」图标也用于首页及锁屏卡片。
- 灵动岛展开态把读数、运行时间、预约状态和操作集中到摄像头下方，左右及底边留出圆角空间。三个操作按钮统一使用深色，按下时使用浅色反馈。
- 回到前台时以新活动为起点，逐个替换旧预约。名额不足时优先释放较远的旧预约，保留较近的预约接续。留在 App 期间，预约接力后会自动补回空位。已有的 60 或 90 秒旧会话沿用原间隔，停下后改为 120 秒。
- 网速数字和单位更新时在原位替换，关闭实时活动中这些文本的默认过渡动画。
- 一次 ActivityKit 更新长时间无返回时，时间戳接口允许最新读数继续提交，同一活动最多有两个未返回的调用。两者均被阻塞时继续采样，换到新活动后可立即提交。晚到的旧结果不会覆盖新活动的数据。
- App 重新获得运行机会时，按监控会话标识接回系统中仍有效的活动和预约。多个预约已启动时绑定最新一个。旧活动先结束、新预约仍在等待时，采样继续。用户主动停止监控后清除恢复记录。没有可恢复的活动或预约时，可直接在新版开启监控。
- 预约按系统报告的状态接力，名额不足或创建失败时保留当前网速卡和其余预约。取消操作等待系统确认，慢速清理独立进行。按钮通过带当前活动标识的主程序 Intent 执行。
- 网速很稳定时，约每分钟提交一次有效读数。连续 90 秒没有更新的有效读数由系统标记过期。网卡丢失后显示「无样本」，与真实的 `0 B/s` 分开。很短的突发流量在一秒窗口中取平均。
- 构建流程先运行流量窗口和预约时间表的回归测试，打包时核对主程序、Widget 入口、包名、版本及定位配置。

## 验证后台显示

在另一款 App 中发起一段持续下载，让它跨过至少一次预约接力。长按灵动岛确认「本次监控」继续累计，并在锁屏卡片核对更新时间和样本编号。「本次监控」「运行」和接力倒计时由系统绘制，可以在没有新网速时继续走动。

如果手动移除当前活动，监控会停止。iOS 挂起整个进程时，App 只能在下一次获得执行机会后继续读本机网卡。接力使用 ActivityKit 支持的预约接口，系统决定能否创建、何时呈现以及是否发出提示。

## 在 Mac 构建

使用含 iPhoneOS 27 或更新 SDK 的 Xcode，并安装 XcodeGen。运行 `bash build.sh`，脚本生成工程并将未签名 IPA 输出至 `dist/IslandSpeed-unsigned.ipa`。实际的主程序显式 Intent 路由需要 iOS 27，预约功能需要 iOS 26 或更高版本。

[Apple 的实时活动更新文档](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities) · [预约接口](https://developer.apple.com/documentation/activitykit/activity/request(attributes:content:pushtype:style:alertconfiguration:start:))
