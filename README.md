# IslandSpeed 1.1.7 · 防抖与预约接力实验版

将 ZIP 解压到现有 xq666i/islandspeed 仓库根目录覆盖同名文件，新增 App/RateStabilizer.swift 也必须上传。保留原有 Shared/SpeedAttributes.swift、App/NetworkMeter.swift、App/BackgroundMeasurement.swift（LocationSession）、Widget/Info.plist 和 .github。build.sh 会重新生成 Xcode 工程；预约活动需 Xcode 26 或更新 SDK，旧编译器将禁用预约路径。定位权限可选，定位机制未变。PiP、音频、快捷指令仍不编入。

## 显示与防抖
- 每 0.25 秒采样，最近四样本平均；默认 1 秒最短提交间隔，可选 1/2/3/5/10/15 秒。默认关闭心跳，显示值不变不提交。
- B/s 和不足 500 KB/s 保留原精度；500–999 KB/s 以最后发起的显示值为基准，偏差不足 20 KB/s 时保持旧显示。1–不足 10 MB/s 滞回阈值为距旧显示中心不足 0.08 MB/s，10 MB/s 及以上为不足 0.8 MB/s。跨单位或精度档位不额外滞回。上传、下载独立判断。数值误差是节省更新的代价，主 App 仍显示普通平滑采样。
- 固定宽度保持。长按活动新增系统计时对照（活动年龄），不需要 App 每秒调用更新；不代表网速也在更新。
- 无心跳时无定时过期日期，系统挂起进程时可能一直显示旧值；进程仍运行时连续无有效样本会尝试标记待采样。返回前台自动续期仍为 60 秒，可关闭。

## 实验（默认关闭）
1. 预定活动接力：停止监控后开启开关，选择间隔（60/90/120/180/300 秒）及 1–3 个预约，再启动监控。系统接受的预约数量可能低于设置。预约采用 iOS 26 的 ActivityKit startDate API，必须提供 AlertConfiguration（默认提示音）。系统可在后台到时启动，但 App 仍须运行才能识别接力并结束旧活动；若 App 被挂起，可能短暂或持续存在多个活动，或显示待采样。停止时尝试取消预约，重新启动监控前清理残留活动。预约耗尽需在前台手动补充；后台无法补充。单独关闭前台自动续期便于测量。注意预约占用活动名额，可能导致前台重建失败；保留旧活动。
2. 更新额度恢复：每个活动每 90 次发起更新，暂停提交 15/30/60 秒（默认关），后台采样持续；暂停期间显示旧值，不保证系统额度恢复。
3. 诊断：当前活动发起次数、contentUpdates 观察次数、最近观察时间、防抖抑制检查、预约/接力、冷却剩余，以及原采样与返回统计。观察内容更新也不代表屏幕实际渲染。可复制诊断。

建议先测默认防抖版（关闭接力、冷却和前台自动续期）；再测试单个 120 秒预约；最后独立测冷却。尽量使用相同网络负载。未通过 Xcode/iOS 真机完整构建验证，预定活动能否延长刷新仍待实测。
