# IslandSpeed 1.1.9 · 即时接力与安全预约重置

版本 1.1.9，构建号 13。增量替换包基于已实测的 1.1.8 接力队列重置版，并合并主程序 Intent 强制路由修复。覆盖同名文件，**必须包含隐藏目录 `.github/workflows/build.yml`**。保留其余项目文件（包括上一版的 Shared/RelayIntent.swift、App/RelaySchedule.swift）；继续通过 Actions Artifacts 获取 IPA，不发布 Release。

- 立即接力不受活动年龄或剩余预约数量限制（保留3秒防重复、执行中互斥、旧按钮检查）。当已有4个预约时先释放最远待启动预约，再申请新活动。若系统创建失败，保留原活动和其余预约，尽可能恢复被释放的预约；同一活动不会连续消耗旧预约。
- 新活动创建成功后立即绑定采样并增加累计接力次数，再结束旧活动。按新活动启动时刻和设定间隔安排4个新预约，例如180秒间隔对应+3/+6/+9/+12分钟。
- 安全替换：先申请第一个新预约，成功后逐个替换旧预约；首次后台预约因 visibility 等错误被拒时，保留尚未取消的预约。中途失败保留仍有效的新旧预约，记录不完整状态。仅真实预约成功才更新倒计时，绝不伪造4/4或3分钟。
- GitHub Actions 强制使用 xcode-27 runner；构建脚本检查 iOS 27 SDK 以及 App、Widget 两个目标的路由编译宏，不允许默默降级。LiveActivityIntent 主程序执行路径用于验证系统能否授权后台预约；扩展转发不继承该权限。
- 保留原有采样、防抖、定位、长按实验、显示布局、前台60秒续期与正常定时接力（仅消费一个预约）。前台续期及展开实验也使用安全队列替换。
- 新增队列重置状态、逐个取消与新预约日志；保留累计接力与跳过/失败区分。

测试：停止旧版监控再安装；确认诊断首行 1.1.9，Intent 路由为 iOS 27 显式主程序路由。开启监控，在剩余预约4/4时切换到其他 App，长按灵动岛点一次立即接力；不要立即返回 App。观察活动 ID、累计接力、本轮运行、预约数量及倒计时。再测试首次自动接力后剩余3个的情况。复制诊断，重点关注按钮入口、旧预约取消、新预约第1个成功或拒绝原因、队列重置状态。

本地验证：Swift 源码语法解析（含路由宏）、14种模拟 ActivityKit 队列场景、shell/YAML 和 ZIP 检查。未执行 Xcode SDK 类型检查或真机验证；后台重新预约权限、自签后 Intent 路由及 runner 账号可用性仍需实际确认。首次预约拒绝时不保证能恢复已释放的一个名额，也无法强行重置倒计时。
