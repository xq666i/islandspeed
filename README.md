# IslandSpeed 1.1.3 · 定位权限修复 / 定宽显示 / 活动续期实验

本包含 1.1.2 的全部替换文件及本次定位权限修复。将本包解压到 GitHub 仓库根目录，覆盖同名文件。保留原有 Shared/SpeedAttributes.swift、App/NetworkMeter.swift、Widget/Info.plist 和 .github 工作流。GitHub Actions 使用 build.sh 和 XcodeGen 重新生成工程；Mac 手动打开工程前先运行 xcodegen generate。旧 WAV 无需删除，不会打包。

- 定位为可选：无需授权即可开启网速，不自动弹出定位授权。若授权为使用期间允许或始终允许，监控开启且 App 在前台时自动启动辅助定位。监控期间撤销权限只停止定位，不结束网速活动。无定位权限时离开 App 可能很快停止采样。精确位置可关闭，坐标不保存或上传；停止监控时停止定位。只使用自定义实时活动，不再创建后台测量进度活动。
- 授权：未授权时点击申请定位权限，选择使用 App 期间允许，不要选择仅允许一次；然后点击升级为始终允许。系统可能不立即显示升级弹窗，也可能忽略重复请求。若未弹窗，请点击打开系统设置检查。若签名后权限选项异常，检查最终 IPA 的主 App Info.plist 是否保留 NSLocationAlwaysAndWhenInUseUsageDescription、NSLocationWhenInUseUsageDescription、UIBackgroundModes 中的 location。两版原权限声明一致，无法确定真机授权异常具体原因。
- 0.25 秒采样，最近 4 个有效样本平均。默认 1 秒提交间隔，亦可选 2/3 秒进行对比。显示值完全相同则每 5 秒提交一次新采样作为心跳，未变化时不重复提交；活动过期时间仍为 30 秒。单个活动只允许一个更新调用在途，更新等待不阻塞采样和续期控制。
- 默认启用 60 秒活动续期实验。后台满 60 秒后尝试新建；普通 Activity.request 在后台通常会被 iOS 拒绝。被拒绝则保留原活动，本次监控不再后台尝试；回到 App 时旧活动达到 60 秒会尝试自动重建。也可在 App 中手动点击立即重建灵动岛。新活动建立成功才立即结束旧活动，切换期间系统可能短暂显示两个活动；创建失败则保留旧活动。60 秒不是苹果公布的限制。
- 紧凑界面固定上下行各 50 pt 内容宽度，数字及单位分别固定宽高；最小模式使用较窄布局；实际灵动岛外框由系统决定。

建议测试：默认设置运行 5 分钟，切换至 Safari 下载或播放流媒体，观察网速变化；降频后回 App 记录后台报告、活动重建状态、有效样本、提交发起/返回次数和最近返回耗时。自动续期关闭后分别测试 1/2/3 秒提交间隔，比较降频出现时间。提交返回不代表系统已绘制画面。无需结束定位或重置采样来手动重建；如果重建失败，可停止并重新启动监控。

本包完成 Swift 语法解析及配置/打包脚本检查，但未使用 iOS SDK 编译，也没有真机验证。系统后台运行权限、活动创建权限和实际刷新率不能保证。
